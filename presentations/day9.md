# Compiler Errors

- Some code fails to compile
- Red dots show where the problem is
- Error message gives an explanation
- Sometimes, the message is useless
- Error location is usually a good hint

---

# Runtime Errors

- Program compiles, but isn't working quite right
- Read the description and see what it *should* be doing
- Use "Step Slowly" to watch the program as it executes and see where it's going wrong
